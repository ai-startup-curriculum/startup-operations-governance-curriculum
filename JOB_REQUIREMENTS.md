1. 2. Anchored the taxonomy against the three-axis model authored in [`startup-foundations`](https://github.com/ai-startup-curriculum/startup-foundations) — the [dependency graph](https://github.com/ai-startup-curriculum/startup-foundations/blob/main/FUNCTIONAL_CURRICULA.md) (People / Legal / Operations / Governance branch owned by this repo), the [stage ladder](https://github.com/ai-startup-curriculum/startup-foundations/blob/main/STARTUP_STAGES.md) (IDEA → PRE-SEED → SEED → SERIES-A → GROWTH → MATURE), and the founder's operating loop (decide → allocate → communicate → measure) — none of which this track re-teaches.
3. Applied the **ownership rule** — this repo owns the People / Legal / Operations / Governance pillar depth from IDEA-stage entity formation through the pre-IPO COO / CPO / GC / Corporate-Secretary seat. Everything else defers per the *Ownership map — quick reference* section below.
4. This cycle: fanned parallel WebSearch across role-title landing pages on builtin.com / builtinnyc.com / builtinsf.com / builtinboston.com / builtinchicago.org / builtinaustin.com, jobs.ashbyhq.com, boards.greenhouse.io, jobs.lever.co, Society for Corporate Governance careers board (careers.societycorpgov.org), VC portfolio boards (jobs.generalcatalyst.com, jobs.madrona.com, careers.redpoint.com, careers.ocaventures.com, Cherry Ventures / Craft / Thrive), specialist privacy boards (privacy.jobs, iapp.org jobs, teachprivacy.com), specialist in-house legal boards (goinhouse.com, law.com, TechGC job-board summaries), specialist fintech / crypto boards (chainjobs.io, web3.career), and direct careers pages at Anthropic / OpenAI / Mistral / Firecrawl / Stedi / Verkada. Complemented with WebFetch of individual posting URLs where the target board returned HTML. Ashby pages are client-rendered and WebFetch returned empty bodies, so date_observed and salary bands were cross-verified via mirror sites (dreamworkhq, crustdata, vaia, zapply, teal, freehire, startup.jobs); where a posting's date was ambiguous within August-November 2026 it was retained only when at least two mirror sources concurred on in-window status. LinkedIn / Wellfound / YC Work-at-a-Startup / VC-portfolio authenticated boards required authentication and were sampled indirectly via WebSearch summaries. Computed per-theme frequency against a strict n=43 in-window denominator.
5. Compared 2026-11 posting frequencies against the { ≥ 3 distinct in-window postings, ≥ 0.30 frequency, no existing module can extend } continuity-bias threshold. Every net-new theme candidate failed at least one gate — see *Emerging themes — below curriculum threshold this cycle* for the five candidates evaluated (four carry-forward + one new).
